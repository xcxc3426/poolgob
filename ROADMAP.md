# Roadmap

## Included in 0.1.0

- Eight seeded fictional pool histories and a declared missing-data boundary.
- Single-pool exit model, depth surface, cohort measurements and source-linked rules.
- Twelve research views with PNG, CSV, case and receipt exports.
- Original 8-bit goblin and code-composed social cover.
- A persistent Poolgob Grok Bot role and reusable workflow instructions.
- Reference examples, three sensitivity studies and mathematical/provenance tests.

## Next engineering work

| Work | Acceptance criterion |
|---|---|
| External replay fixtures | Provider provenance, observation slots, retrieval time and precise units |
| Pool-specific adapters | Independently verified math, rounding and token-extension behavior |
| Account classification | Evidence for protocol/custody exclusions and explicit coverage |
| Provider comparison | Same cutoff and normalization across independently captured sources |
| Authenticated handoff | Real configured-account state and independently verifiable execution receipts |
| Browser QA | Real engine checks, download behavior, mobile layout and accessibility review |

## Later studies

Investigate irregular observation intervals, confidence under incomplete account coverage, quote differences across route models, and friction under explicit liquidity-shock assumptions. Publish the input fixtures and the comparison convention alongside each result.

## Scope discipline

Keep the research tool useful without requiring a token launch or custody. New live-data or on-chain components should be named and tested as new components, not implied by a screenshot or a logo.

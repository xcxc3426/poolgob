# Poolgob art and figure provenance

## Original mascot

`poolgob.png` is an original image generated for Poolgob on 29 October 2026 using the built-in image-generation tool. It used no reference image or earlier project mascot. The opaque graphite background and cobalt/copper pixel style were requested deliberately.

The logo is illustrative branding. It does not encode pool activity, holder behavior, an AI state or measured data.

## Final mascot prompt

Use case: logo-brand. Asset type: original 8-bit mascot logo for a new project named Poolgob. Primary request: design a cool compact pixel goblin, entirely new and unlike round robots, pea mascots, paper origami characters or generic AI brain icons. Subject: head and small shoulders of a mischievous watchful goblin in three-quarter view, cobalt-indigo skin, two very long angular asymmetrical ears extending sideways, a long crooked pointed nose, pale ivory narrow eyes with dark pupils, a slightly uneven grin with exactly one small ivory tusk. He wears a simple oversized burnt-copper hood with a deep charcoal outline; the ears project from the hood. No arms visible, no additional props. Style: authentic bold retro 8-bit pixel sprite, roughly a 64-by-64 logical pixel grid enlarged cleanly, large deliberate square pixels, hard stair-step contours, flat color clusters, extremely restricted palette, no gradients, no smooth anti-aliasing, no 3D rendering, no painted texture, no soft shadow, no shine. Composition: centered single head-and-shoulders character, readable strong silhouette, square canvas, generous plain solid very-dark graphite background matching #13171b. No text or letters, no wordmark, no coins, no charts, no trading screens, no scenery, no frame, no watermark. Personality: patient, shrewd, charmingly unimpressed; an observer of tiny liquidity pools, not a villain. Make it visually distinctive and polished as a small GitHub logo.

## Numerical figures and cover

The twelve numbered PNGs beside the README are native Canvas renderings of the application's research views, generated by `capture.mjs` from the reference dataset and implemented analysis. They are not image-model mockups, browser captures or screenshots of the Grok Bot product.

`poolgob-cover.png` is a code-composed 1600 × 800 cover using the original mascot and deterministic typography. The mascot pixels were not altered.

All exact text, values, plots, heatmaps, tables and diagrams are drawn by application code. The original mascot is the only generated raster artwork used by the project.

## Reuse and identity

The project distributes its code, documentation and supplied artwork under its MIT license to the extent applicable. No third-party game sprites, stock mascot, chain logo or provider logo is included. No name or trademark clearance is claimed.

DejaVu fonts and the optional native renderer are referenced by the tooling but are not distributed in this package.

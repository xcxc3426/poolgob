## Project-specific definitions

Poolgob's role instructions, synthetic data, research rules, cohorts, packet schemas and `cpmm-demo-v1` are original project definitions. They are not official Grok Bot configuration formats or an implementation of another protocol's production contracts.

The model's 30 bps fee is a declared study parameter. It is not a claim that every Solana pool charges that fee or distributes it the same way.

The repository supplies no token contract address, provider-backed market data or externally verified execution receipt. It is independently named and has no claimed affiliation with the referenced providers.
